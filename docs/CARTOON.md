# Mosaic Field Notes cartoon player

`src/studio/media/CartoonPlayer.jsx` takes a canonical reviewed `script`, an `audioFor(segment,index) -> Promise<Blob>` callback, optional `onStatus(text)` and optional `reducedMotion` learner preference. Root media APIs own account authorization, immutable source/version binding, script generation/review and audio admission. The player does not accept arbitrary remote assets, execute generated code, request a microphone, clone voices or create factual graphics.

The original Field Notes vector fallback (`cartoon-assets.js`) provides an observatory, invention room, glass garden and riverside. Mira and Kit have distinct clothing, faces, gaze, talking mouths and talk/think/celebrate gestures. These are fictional scene framing, not diagrams or claims about the learning topic. Geometry and animation are authored, fixed choices. Their motion is deterministic from narration time. It is deliberately not phoneme lip sync.

Playback prepares the approved scenes' actual narration only after an explicit click, concatenates decoded audio with quarter-second pauses and drives scene transitions from decoded duration. It supports pause/resume, scene navigation, speed, captions, still artwork, per-scene sources, complete transcript, transcript download and an ungraded reflection comparison. Audio clips are cached for the mounted episode, including after a later scene fails. Leaving the episode stops audio/recording and closes its AudioContext. A source/script identity change invalidates pending playback intent. The integrated `audioFor` now retrieves exact approved segments from persistent private storage before generating; the component cache also avoids duplicate decoding. See MEDIA-LIFECYCLE.md.

Canvas captions paginate every approved word; page timing is proportional within a scene, not provider word timestamps. At widths up to 700px a readable DOM caption replaces the canvas caption strip. The complete transcript is available regardless of playback. System and learner reduced-motion preferences initialize still artwork, which can also be chosen manually. This is tested behavior, not a WCAG conformance claim.

“Download narrated video” renders a real 1280×720 WebM with audio and burned-in captions using canvas captureStream + MediaRecorder. It runs at normal speed, regardless of playback speed. Keeping the tab visible is required; hiding it cancels rather than claiming a completed render. Cancellation discards the in-progress file. The WebM is finalized with measured Duration metadata before download; otherwise Chromium exports report Infinity. The finalizer accepts only bounded recorder output, rejects indexed/checksummed shapes it cannot safely amend and preserves encoded audio/video bytes. Metadata follows the [Matroska element specification](https://www.matroska.org/technical/elements.html). Video export support is detected; unsupported browsers retain playback/transcript with a clear message. The browser assembly limit is ten minutes and 128 MiB of encoded video. This is a browser export, not a server render queue, MP4 pipeline or offline background renderer.

## Cartoon art collection — 3 November 2026

`cartoon-library.js` maps the same four reviewed scene IDs and two presenter IDs onto two curated visual treatments: **Prism anime** and **Paper comedy**. No source words, source references, model prompt, approved identity, stored audio key or game rules are rewritten by this selection. The media script schema is unchanged. `public/cartoons.html` is an owner-private Site preview of the production component with the short authored fractions sample.

The production inventory is 24 backgrounds (three alternatives for each of four settings in each style) and 28 transparent animation sheets (Mira and Kit × two styles × idle, talk, explain, think, react, celebrate, walk). Raw high-resolution originals and resumable provider receipts remain in `../output/cartoon-variety/raw/`. Images use Sorceress GPT Image 2.5 Sunburst; animations use Wan 2.7 and Sorceress Corridor Key. Two initial Imagine 1.5 pilots failed with a reported provider outage; the successful replacement pilots are independently identified. Generated visual media is decorative, fictional scene framing, never a factual diagram or evidence source.

Only the chosen style and setting collection load. Three concurrent requests, a per-image 30-second timeout, cancellation on selection changes/unmount/failure, exact image-dimension validation and a decoded-pixel budget bound the loader. Changing a setting reuses the loaded cast. Packaged sprites retain a common crop across a character's clips so feet and scale do not jump due to per-frame trimming. SHA-256 hashes and generation/keying IDs accompany every manifest entry. All runtime artwork comes from local curated paths; no model-provided URLs enter the renderer.

The deterministic director uses the audio clock for entrance, speaking, explaining and listener reaction beats. Pause holds a frame; seeking and playback speed remain tied to narration. Still artwork selects a fixed pose while caption pages advance. Gestures and speaking mouths are scene-level animation, **not phoneme-aligned lip sync**. Export captures one artwork pack and disables cosmetic changes until recording finishes. Existing voice cache, complete transcripts, sources and forced export captions remain intact.

If the selected pack cannot load, the user receives a retry control and an explicit Field Notes fallback. Play/export wait for matching artwork; ongoing narration can still be paused. No extra AI generation is charged when switching art or replaying the sample. This does not introduce an MP4 renderer, a server-side video queue, arbitrary new cast generation or unrestricted cinematic story direction.

Current verification evidence, actual results and limitations are recorded in `../output/cartoon-variety/acceptance.json` and the rendered release report; the older acceptance above remains historical.
